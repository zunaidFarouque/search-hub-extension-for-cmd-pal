# Adding screenshots for the README

Use these files with the **Demo / screenshots** section in [README.md](/README.md) (and [.github/README.md](/.github/README.md), kept in sync).

- **hub.png** — main hub command with a prefix and query (optional suggestions visible).
- **providers.png** — **Configure search providers** list or detail.

Recommended width for GitHub: about **1200–1600 px** (the README can use HTML width on img if you want a smaller display size).
